Python example

A short program that calculates the total, average and best-performing subject from a set of marks.

# Marks analysis (sample data)
marks = {"Python": 88, "Java": 82, "Data Analytics": 91, "Web Design": 85}

total = sum(marks.values())
average = total / len(marks)
best = max(marks, key=marks.get)

print(f"Total: {total}")
print(f"Average: {average:.2f}")
print(f"Best subject: {best}")
Press “Run program” to see the output.

The numbers above are sample data, not real marks.
